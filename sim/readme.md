## Training starten

```bash
cd sim
../.venv/bin/python start_training.py
```


## Modell auswerten

Neuestes Modell aus `sim/models/` fahren lassen:

```bash
cd sim
../.venv/bin/python evaluate.py
```

Ein bestimmtes Modell auswerten:

```bash
cd sim
../.venv/bin/python evaluate.py models/ppo_2026-11-20_14-23.zip
```
